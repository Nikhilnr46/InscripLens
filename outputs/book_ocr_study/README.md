# Printed-source OCR baseline

`python outputs/check_book_ocr.py` runs the locally installed Tesseract Kannada LSTM engine on three fixed regions of EC IX Kannada page 224, Hoskote 110. It requires `tesseract` on PATH and installed `kan` language data. No new model was trained, no stone classifier was used and no automatic page layout was evaluated. This small test concerns one historical printed page, not books generally.

The resulting Kannada text is nonempty but visibly erroneous: the opening formula and repeated sri text are misrecognized, line numbers become symbols or text, and historical letters are unreliable. No independently checked transcription was available for a defensible CER or accuracy score. Engine confidence must not be treated as measured accuracy. The local language-model file's upstream variant is not established by this test.

The app's **Published reading review** view displays the saved column drafts in editable fields and exports original OCR plus edits with provenance. This is a saved-example review workflow, not a general book upload/recognition feature. Corrections are session-only until downloaded; no stone labels or evaluation references are overwritten.

Defensible demonstration claim: “InscripLens provides experimental inscription analysis and a reference-review workflow, including an editable printed-source OCR draft generated by pretrained Tesseract.” Do not claim the stone model recognizes books, that the book transcription is accurate, or that reading text equals translating it.

Next useful check: independently type a small printed passage, compare raw OCR without silently modernizing historical letters, and report codepoint edit error with the transcription conventions. If trying modern book text, use a separate clearly identified sample and report its results separately from this historical edition.
